Description:
A custom C library implementing standard C library functions and additional functions that are not part of the library.
The library contains three groups of functions:

1- Libc functions:
ft_isalpha.c|ft_isdigit.c|ft_isalnum.c|ft_isascii.c|ft_isprint.c
ft_strlen.c|ft_memset.c|ft_bzero.c|ft_memcpy.c|ft_memmove.c ft_strchr.c|ft_strlcpy.c|ft_strrchr.c|ft_strlcat.c|ft_toupper.c ft_tolower.c|ft_strrchr.c|ft_strncmp.c|ft_memchr.c|ft_memcmp.c ft_strnstr.c|ft_atoi.c|ft_calloc.c|ft_strdup.c

2-Additional functions:
ft_substr.c|ft_strjoin.c|ft_strtrim.c|ft_putchar_fd.c|ft_putstr_fd.c|ft_putstr_fd.c|ft_putnbr_fd.c|ft_strmapi.c|ft_striteri.c|ft_itoa.c|ft_split.c|ft_putendl_fd.c

3- Linked list:
ft_lstnew.c|ft_lstadd_front.c|ft_lstsize.c|ft_lstlast.c|ft_lstadd_back.c|ft_lstdelone.c|ft_lstclear.c|ft_lstiter.c| ft_lstmap.c

Instructions:
To compile and run this project you will need:
- gcc compiler with flags -Wall -Wextra -Werror
Makefile is using to build libft.a and it includes several rules:
* make all: compiles all functions
* make clean: removes generated object files (.o)
* make fclean: removes both objects and libft.a
* make re: restarts the compilation (flean followed by make all)
